# Paper Reflow Reader

원어(영어) 금융·경제 논문 PDF를 고품질로 추출해, 타이포그래피를 자유롭게 조정하며 읽는
**리플로우 뷰어**. macOS 우선(Apple Silicon), 코드는 Windows 이식 가능하게 작성.

명세: [PAPER_READER_SPEC.md](PAPER_READER_SPEC.md) · 진행 계획: [PLAN.md](PLAN.md)

## 구조

```
pipeline/   1단계 — PDF 추출 파이프라인 (Python + MinerU + PyMuPDF)
app/        2단계 — 리플로우 뷰어 (Electron + React + TypeScript + Vite)
```

두 단계는 중간 포맷 `document.json`(명세 §5)을 계약으로 분리된다.

## 원문 + 번역 PDF 저장

논문 상단의 **내보내기** 버튼에서 저장 미리보기를 연다. A3/A4 가로 용지,
원문과 번역의 좌우 폭, 번역 글꼴·글자 크기(pt)·줄간격·문단 간격을 조정하고 **PDF 저장**을 누르면
저장 위치를 선택할 수 있다. 종이 바깥 여백, 원문과 번역 사이 간격, 번역 칸 안쪽의
위·아래·좌우 여백을 각각 mm 단위로 조정한다. 슬라이더·증감 버튼·숫자 입력을 사용할 수 있다.
이 설정은 앱 공통 기본값으로 저장해 다른 논문이나 앱 재시작 후에도 바로 불러온다.

원문 PDF의 텍스트와 벡터 도표를 그대로 삽입한다. **살짝 넘치는 쪽만 글자 크기 줄이기**를
켜면 해당 원문 쪽의 번역 글자만 최대 10%(최소 8pt) 줄여 한 장에 맞춘다. 줄간격 배율과 여백은
유지하며, 현재 쪽의 실제 크기를 미리보기에 표시한다. 크게 넘치는 번역은 같은 원문을 왼쪽에
반복한 다음 장으로 이어진다. 설정을 바꾸어도 보고 있던
원문 쪽을 유지한다. 한 장 전체/가로 맞춤과 50–125% 확대, 페이지 선택, 기본 배치 초기화를 제공한다.
번역 탭이나 PDF 미리보기를 열면 빠진 본문 문단과 각주만 추가로 번역한다.
번역 보충·원문 추출이 끝나기 전에는 PDF 저장을 기다린다. 기존 HTML 내보내기는 미리보기 왼쪽 아래에서 사용할 수 있다.

기본 PDF 파일명은 `Ben-David et al. (2018) - Do ETFs Increase Volatility - 원문+번역.pdf`처럼
저자·연도·제목을 포함한다. 원문 첫 페이지의 저널 발행 정보, 작성일 또는 저작권 연도를 사용하며,
본문에서 인용한 연도와 PDF 파일 생성일은 쓰지 않는다. 확인할 수 없는 정보는 미상으로 표시한다.

번역의 위·아래첨자와 네 가지 LaTeX 구분자를 렌더링한다. 각주 번호는 원문 각주 팝업에 연결하고,
PDF에는 각주별 한국어 번역을 번호와 함께 표시한다. 일반 숫자와 위첨자 번호를 모두 인식하고,
원문 텍스트층이 있으면 빠진 번호와 다음 페이지 하단의 각주 연속분을 복원한다.
각주 번역이 남아 있으면 저장을 기다린다. 회전된 표의 깨진 추출 조각은 숨기며 정상 한국어 설명은 보존한다.

PDF 회귀 검증은 `cd app && npm run test:pdf`로 실행한다. 실제 Electron 미리보기·저장 경로를
격리된 임시 데이터로 검사하며, 사용자 라이브러리나 AI 서비스를 수정·호출하지 않는다.

**설정 → AI → 자동 → 원문+번역 PDF**를 켜면 새로 추가한 논문의 추출과 번역이 끝나는 즉시
다운로드 폴더의 `Galpi`에 PDF를 저장한다. 기본값은 꺼짐이다. 자동 번역 토글이 꺼져 있어도
자동 PDF에 필요한 번역은 수행하며, 요약을 기다리지 않고 먼저 PDF를 저장한다.
수동 내보내기에서 정한 용지·글꼴·여백 설정을 사용한다. 라이브러리의 **PDF 저장됨 ↗**로
저장 위치를 열 수 있으며, 같은 이름의 파일은 덮어쓰지 않고 번호를 붙인다.
빠진 본문·각주 번역은 남은 항목만 제한 재시도하고, 누락이 남거나 AI 인증·한도 오류가 나면
완성되지 않은 PDF를 저장하지 않고 카드에 오류를 표시한다.

**처리 속도**는 부하 최소 / 자동(기본) / 빠르게 중 선택한다. 부하 최소는 번역 1묶음과
CPU 코어 절반으로 추출하고, 자동은 CPU 부하와 가용 메모리에 따라 번역 1–4묶음을 병렬 처리한다.
빠르게는 최대 4묶음과 늘린 추출 스레드를 사용한다. 자동에서도 자원이 여유로우면
추출 스레드와 우선순위를 높인다. 메모리가 부족하면 동시성을 줄이고, 선택 번역·채팅을 위해
AI 큐 한 칸을 예약한다. 추출은 기본 6쪽씩 처리하며, 자원이 여유로운 자동 모드에서는 12쪽,
빠르게 모드에서 메모리가 충분하면 24쪽씩 처리해 엔진 반복 기동을 줄인다.
큰 묶음은 첫 추출 결과가 보이기까지 더 오래 걸릴 수 있다. 추출 백엔드와 high 품질 설정은 유지한다.
번역 자체는 외부 AI 서버에서 처리하므로 서버 지연·한도와 추출 시간이
전체 처리 시간에 영향을 준다. PDF 자동 저장은 원문 이미지 미리보기 로딩을 생략하며,
원문 PDF 자체를 삽입해 텍스트·벡터를 보존한다.

자동 처리 회귀 검증은 `cd app && npm run test:automatic`으로 실행한다. 실제 번역 스케줄러,
캐시, 자동 파이프라인과 Electron PDF 생성을 사용하며 AI 응답은 모의 서비스로 대체한다.
병렬 시간 비교는 모의 서버 지연을 사용한 검사로, 실제 AI 서버의 속도 보장은 아니다.

## 개발 셋업

### 1단계 (pipeline)

```bash
cd pipeline
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# 추출 실행
python extract.py <input.pdf> <output_dir>
```

### 2단계 (app)

```bash
cd app
npm install
npm run dev        # Vite dev 서버 + Electron
```

## 플랫폼

- **macOS (Apple Silicon)**: MinerU MLX 백엔드로 가속. 주 타깃.
- **Windows**: 뷰어는 동작. 추출은 `pipeline`/CUDA 백엔드 필요(미검증).
